## 2. Unsafe Search (P7.3)

The following were searched across the device stack: `unsafe`, raw pointers,
MMIO, BAR, DMA, interrupt, CUDA, ROCm, wgpu.

- `qeos-gpu-compute`, `qeos-node`: `#![forbid(unsafe_code)]` — zero unsafe.
- `device-manager`, `hardware-abstraction`: **REAL** host-testable logic, no
  raw physical access; MMIO only via `MmioMapper` (simulated bundled).
- No CUDA/ROCm/wgpu dependency or vendor driver is present →
  vendor GPU backend is **UNAVAILABLE**.
