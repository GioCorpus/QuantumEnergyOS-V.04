## 1. Executive Summary

P7.5 introduces a new workspace crate **`crates/qeos-cluster`** that implements
the distributed node architecture: cryptographically bound node identity,
a validated registration lifecycle, cluster membership semantics and the
control-plane authority model with heartbeat-based failure detection.

**Baseline (P7.4):** 678 tests. **After P7.5:** 699 tests (+21), clean compile,
clippy-clean, zero unsafe.

---

## 2. P7.5-00 — Node Architecture Audit

The `qeos-node` platform (lifecycle, health, inventory) from P7.2 is the node
runtime. `qeos-cluster` is the distributed layer. A physical node-to-node
**network transport is NOT IMPLEMENTED** in this phase; reachability is modeled
via heartbeats. The transport is a later integration point.

---

## 3. P7.5-01 — Node Identity

`crates/qeos-cluster/src/identity.rs`:
- `NodeIdentity { node_id, credential_fingerprint, capabilities, software_version, hardware }`.
- Credentials are stored as a **SHA-256 fingerprint** (never the plaintext
  secret) → control plane can verify proof-of-knowledge without storing secrets.

**REAL.** Tests: 3.

---

## 4. P7.5-02 — Node Registration

`crates/qeos-cluster/src/registration.rs`:
- `NodeRegistrationState`: DISCOVERED → PENDING → REGISTERED → HEALTHY ⇄ DEGRADED,
  plus OFFLINE and terminal REVOKED.
- Validated transitions; offline reconnect must re-authenticate (`PENDING`);
  revocation is terminal.

**REAL.** Tests: 4.

---

## 5. P7.5-03 — Cluster Control Plane

`crates/qeos-cluster/src/control_plane.rs` — `ControlPlane`:
- `register` (credential-verified admission), `heartbeat` (credential +
  generation check + liveness), `drain`, `revoke`, `remove`, `tick`
  (heartbeat-timeout detection).
- Single-authority membership; no split-brain assumption.

**REAL.** Tests: 6.

---

## 6. P7.5-04 — Node Failure

Handled: node crash/heartbeat loss (`expire_missing` → OFFLINE), duplicate
registration (rejected while active), stale/duplicate connection (generation
mismatch → `StaleHeartbeat`), reconnect, credential mismatch.

**REAL.** Tests cover each failure class.

---

## 7. P7.5-05 — Cluster Membership

`crates/qeos-cluster/src/membership.rs`:
- The **control plane** decides membership (join/leave/revoke/stale).
- `Membership` tracks member state, reachability, last heartbeat and session
  generation; rejects duplicate active registration; removes stale records.

**REAL.** Tests: 7.
