# P6.2-01 Memory Model Audit & Hardening — Implementation Plan

## Current State Analysis

### Already Implemented (Baseline)
| Component | File | Status | Gaps |
|-----------|------|--------|------|
| `PhysAddr` | `memory/physical.rs` | `struct PhysAddr(pub usize)` | No alignment, checked arithmetic, range validation, arch awareness |
| `PhysPage` | `memory/physical.rs` | `struct PhysPage(pub usize)` | No boundary validation, conversion safety |
| `VirtAddr` | `memory/virtual_.rs` | `struct VirtAddr(pub usize)` | No canonical validation |
| `VirtPage` | `memory/virtual_.rs` | `struct VirtPage(pub usize)` | Basic |
| `MapFlags` | `memory/virtual_.rs` | READ/WRITE/EXEC/USER | Missing GLOBAL, CACHE, PRESENT |
| `VirtualMemoryManager` | `memory/virtual_.rs` | Flat `BTreeMap` | Not multi-level; no TLB; no walk; no arch semantics |
| `PhysicalMemoryManager` | `memory/physical.rs` | `BTreeSet<usize>` | No buddy allocator; no reserved regions; no ACPI/MMIO handling |
| `KernelHeap` | `memory/heap.rs` | Bump-only, no free | No deallocation; no fragmentation handling |
| `KernelAllocator` | `memory/allocator.rs` | `std::sync::Mutex` | Not `no_std`; not IRQ-safe |
| Paging constants | `arch/x86_64/paging.rs` | Index functions only | No page table entry structs; no walk; no CR3; no TLB |

### Missing / Required for P6.2-01
- [ ] **PhysAddr**: alignment helpers, checked arithmetic, range validation, canonical phys address range
- [ ] **PhysPage**: boundary validation, safe conversions
- [ ] **VirtAddr**: canonical address validation (x86_64 48/57-bit)
- [ ] **VirtPage**: canonical page validation
- [ ] **PageTableEntry**: x86_64 PTE with all flags (P, RW, US, PWT, PCD, A, D, PAT, G, NX)
- [ ] **PageTable**: Multi-level (PML4→PDPT→PD→PT) with ownership, allocation, cleanup
- [ ] **PageTableWalker**: Walk, map, unmap with proper permissions
- [ ] **TLB**: `invalidate_page`, `invalidate_range`, `switch_address_space` (CR3 write)
- [ ] **NX**: Enforce NX bit in PTE; test executable vs non-executable
- [ ] **Address Space Isolation**: Separate kernel/user page tables; no user access to kernel memory
- [ ] **Tests**: Comprehensive test coverage for all above
## Implementation Order

### Step 1: Strengthen PhysAddr / PhysPage
**Files**: `kernel/src/memory/physical.rs`
- Add `align_up`, `align_down`, `is_aligned`
- Add `checked_add`, `checked_sub`, `checked_mul`
- Add `is_canonical()` for physical address width (52-bit on x86_64)
- Add `PhysPage::from_addr()`, `PhysAddr::from_page()`
- Add boundary checks (no overlap with reserved regions)

### Step 2: Canonical Virtual Address Validation
**Files**: `kernel/src/memory/virtual_.rs`, `kernel/src/arch/x86_64/paging.rs`
- Implement `VirtAddr::is_canonical()` for 48-bit and 57-bit (LA57)
- Implement `VirtPage::is_canonical()`
- Add `CANONICAL_LOW`, `CANONICAL_HIGH` constants
- Tests for boundary values

### Step 3: Page Table Entry & Flags
**Files**: `kernel/src/arch/x86_64/paging.rs` (new structures)
- `PageTableEntry` with bitfield representation
- Flags: `PRESENT`, `WRITABLE`, `USER`, `PWT`, `PCD`, `ACCESSED`, `DIRTY`, `PAT`, `GLOBAL`, `NX`
- `EntryFlags` bitflags-like type
- Conversion to/from `u64`

### Step 4: Multi-Level Page Table Implementation
**Files**: `kernel/src/memory/virtual_.rs` (replace `VirtualMemoryManager`)
- `PageTable` owning its frames (allocated via `PhysicalMemoryManager`)
- `PageTable::new()` allocates PML4 frame
- `map_page()`, `unmap_page()`, `translate()` with full walk
- `PageTable::switch()` — loads CR3 (stub for host, real for target)
- Proper cleanup on drop (recursive frame deallocation)

### Step 5: TLB Operations
**Files**: `kernel/src/arch/x86_64/paging.rs`, `kernel/src/memory/virtual_.rs`
- `tlb_flush_page(virt: VirtAddr)` — `invlpg`
- `tlb_flush_range(start: VirtAddr, end: VirtAddr)` — loop or `invlpg` batch
- `tlb_flush_all()` — write CR3 (address space switch)
- Host stubs that track flushes for testing

### Step 6: NX Enforcement
**Files**: `kernel/src/arch/x86_64/paging.rs`, `kernel/src/memory/virtual_.rs`
- Set NX bit (bit 63) in PTE when `EXEC` not in flags
- Validate on map: `WRITE && EXEC` -> error (W^X)
- Tests proving code cannot execute from non-EXEC pages

### Step 7: Address Space Isolation
**Files**: `kernel/src/memory/virtual_.rs`, `kernel/src/process/process.rs`
- `AddressSpace` struct owning a `PageTable`
- Kernel address space (shared, higher half)
- User address space (per-process, lower half)
- `switch_to()` context switch hook

### Step 8: Comprehensive Tests
**Files**: `kernel/src/memory/physical.rs`, `virtual_.rs`, `arch/x86_64/paging.rs`, new test file
- Address conversion/alignment/overflow
- Canonicality (low/high/non-canonical)
- Page allocation/mapping/unmapping
- Permissions (R/W/X/U/G/NX)
- TLB behavior (flush tracking)
- Page table walking
- Fault paths (invalid mapping, permission fault)

## Acceptance Criteria (P6.2-01 Gate)

| Criterion | Verification |
|-----------|--------------|
| `PhysAddr`/`PhysPage` have checked arithmetic & alignment | Unit tests pass |
| Canonical virtual address validation works | Tests for 48-bit & 57-bit boundaries |
| Multi-level page tables map/unmap/translate correctly | Integration tests with walk verification |
| W^X enforced at PTE level | Test: WRITE+EXEC -> error; EXEC without NX -> fault |
| TLB hooks exist and are called on map/unmap/switch | Test: flush tracking counters |
| Kernel/user address space separation | Test: user page table cannot map kernel memory |
| All workspace tests pass | `cargo test --workspace` |
| Clippy clean | `cargo clippy --workspace --all-targets --all-features -- -D warnings` |
| Fmt clean | `cargo fmt --all -- --check` |

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Host tests can't test real CR3/invlpg | Use `#[cfg(target_os = "none")]` for real impl; host stubs with flush counters |
| Page table frame leaks | `Drop` impl recursively frees all child tables |
| Recursive page table mapping complexity | Use direct-map offset for page table frames (identity map in kernel space) |
| LA57 (57-bit) vs 48-bit canonical | Make canonical check configurable via `KernelConfig::addr_width` |
